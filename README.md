## English

Hi! I'm **phys-winner**, a developer working on game ports and adaptations for Android.

### What I work on

- **🎮 PC → Android.** My main focus is bringing PC games to Android and adapting them for play on phones and tablets.
- **🥽 VR → flat-screen Android.** I also work on adapting VR games for play on a regular Android screen, without a VR headset.
- **⚙️ ARM32 → ARM64.** I create compatibility modifications to help older 32-bit Android games run on modern ARM64 devices.

I share my projects here so you can follow their development and try available builds.

**My Telegram channel:** [@phys_winner_ports](https://t.me/phys_winner_ports)

### Support

**There is currently no paid content.** Financial support is voluntary and helps me continue developing these projects.

See each repository's README for setup instructions, required game files, compatibility information, and known limitations.

## Русский

Привет! Я **phys-winner** — разработчик, который занимается портированием и адаптацией игр для Android.

### Над чем я работаю

- **🎮 ПК → Android.** Моё основное направление — перенос компьютерных игр на Android и их адаптация для игры на смартфонах и планшетах.
- **🥽 VR → обычный экран Android.** Также работаю над адаптацией VR-игр для обычного экрана Android-устройства, без VR-гарнитуры.
- **⚙️ ARM32 → ARM64.** Создаю модификации для совместимости старых 32-битных Android-игр с современными устройствами на ARM64.

Здесь я делюсь своими проектами: можно следить за разработкой и пробовать доступные сборки.

**Мой Telegram-канал:** [@phys_winner_ports](https://t.me/phys_winner_ports)

### Поддержка

**На данный момент платного контента нет.** Финансовая поддержка добровольна и помогает мне продолжать работу над проектами.

Инструкции по установке, требования к файлам оригинальной игры, сведения о совместимости и известных ограничениях смотри в README конкретного репозитория.
